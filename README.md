##  Featured Projects

###  [Fitness Chatbot](https://github.com/angelkgithub/Fitness_Chatbot)
A fitness assistant web app with a built-in model dashboard. An intent classifier (TF-IDF + logistic regression over 15 intents) reads each message, and a confidence threshold decides whether the bot answers or asks a clarifying question. Replies like BMI and exercise form are computed from data.
- **72.6%** cross-validated accuracy (50 folds); at the default threshold, 84% of messages are answered at 82% accuracy
- Dashboard tabs for performance metrics, confusion matrix, threshold tuning and an NLP pipeline tracer
- `Python` `Flask` `scikit-learn` `pandas`

###  [Curriculum Scheduler](https://github.com/angelkgithub/AlgoFinal)
A Streamlit app that automatically generates class timetables from course, room and enrollment data (Algorithms finals project).
- Greedy, backtracking and constraint-satisfaction scheduling, with room and section conflict detection
- Weekly views, room-usage timetables (7 a.m.–9 p.m.) and CSV export
- `Python` `Streamlit` `pandas` `NumPy`

###  [Employee Team Hub](https://github.com/angelkgithub/EMS-EMPLOYEE)
An internal website for a medical supply company's employees: tool links, training videos, call recordings, org chart and house rules in one place.
- Site-wide search (Ctrl+K), dark mode and a new-hire checklist
- Pre-deploy checker for missing content and broken links, security headers and an optional password gate
- `HTML` `CSS` `JavaScript` `Vercel`

###  [Pokémon TCG Card Browser](https://github.com/angelkgithub/angelkgithub_pokemonTCG)
A card browser built on the Pokémon TCG API, with type filters, debounced search and next-page prefetching.
- `Next.js` `React` `Tailwind CSS`
